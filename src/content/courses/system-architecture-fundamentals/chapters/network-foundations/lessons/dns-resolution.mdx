## 1. Why Do We Need DNS?

Computers communicate across the internet using numeric **IP addresses** (such as IPv4 `142.250.190.46` or IPv6 `2607:f8b0:4005:808::200e`).

Humans, however, remember names like `complexity.dev` or `github.com`.

The **Domain Name System (DNS)** is the globally distributed database responsible for translating human-readable hostnames into machine-routable IP addresses.

---

## 2. The Hierarchical Tree

DNS is structured as an inverted tree:

1. **Root Nameservers (`.` )**: 13 named root authority systems (replicated via Anycast across hundreds of physical global locations).
2. **Top-Level Domain (TLD) Nameservers**: Authorities for `.com`, `.org`, `.net`, `.io`.
3. **Authoritative Nameservers**: The specific server holding the official zone records for a domain (e.g., Cloudflare, Route53, NS1).

```
                      [ Root Level (.) ]
                              │
            ┌─────────────────┼─────────────────┐
            ▼                 ▼                 ▼
        [ .com ]           [ .org ]          [ .io ] (TLD)
            │
            ▼
    [ complexity.io ]                          (Authoritative Zone)
            │
            ▼
     A Record: 198.51.100.24
```

---

## 3. Recursive Resolution in Action

When your application initiates a connection to `api.complexity.io`:

1. **Browser Cache**: Checks if resolved recently.
2. **OS Resolver Cache**: Checks local operating system cache (`/etc/hosts`, systemd-resolved).
3. **Recursive Resolver (ISP or 1.1.1.1 / 8.8.8.8)**:
   - Queries Root (`.`) → receives reference to `.io` TLD server.
   - Queries `.io` TLD server → receives reference to Authoritative nameserver.
   - Queries Authoritative nameserver → receives final `A` record (`198.51.100.24`).
4. **Caching**: Stores result with the configured **TTL (Time To Live)** in seconds.

<InfoCallout type="warning" title="Production Trap: DNS TTL">
If you set a high TTL (e.g. 86400s / 24 hours) and need to failover to a new server IP during an emergency outage, clients will continue routing traffic to the dead IP until their local TTL expires!
</InfoCallout>
